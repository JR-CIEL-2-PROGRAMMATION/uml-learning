# Exercice 1 — Processus d'inscription à une formation

## Énoncé

Modélise le processus suivant :

1. Le candidat remplit un formulaire d'inscription.
2. Le système vérifie si les places sont disponibles.
   - Si oui : le candidat procède au paiement.
     - Si le paiement réussit : une confirmation est envoyée et une place est réservée.
     - Si le paiement échoue : un message d'erreur est affiché, retour au paiement.
   - Si non : le candidat est mis sur liste d'attente.
3. Fin du processus.

### Travail à faire

Dessine ce processus en diagramme d'activité (Mermaid ou PlantUML), avec les bonnes décisions.
