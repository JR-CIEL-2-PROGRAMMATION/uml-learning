# Exercice 1 — Système de commande en ligne

## Énoncé

Modélise un système e-commerce avec les règles suivantes :

- Un **Client** peut passer plusieurs **Commandes**.
- Une **Commande** contient plusieurs **LigneCommande**.
- Une **LigneCommande** est liée à un **Produit** avec une quantité.
- Si une commande est supprimée, ses lignes disparaissent aussi (mais pas les produits).

### Travail à faire

1. Identifie les classes et leurs attributs principaux.
2. Identifie les méthodes utiles.
3. Détermine le type de relation entre chaque paire de classes.
4. Détermine les cardinalités.
5. Dessine le diagramme (Mermaid ou PlantUML).

> 💡 La règle "si X disparaît, Y disparaît aussi" est un indice sur le type de relation à utiliser.
