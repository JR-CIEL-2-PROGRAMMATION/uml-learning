# Exercice 1 — Application de gestion de bibliothèque

## Énoncé

Une bibliothèque veut une application avec les fonctionnalités suivantes :

- Un **Membre** peut : rechercher un livre, emprunter un livre, retourner un livre, consulter son historique.
- Pour **emprunter un livre**, le système doit toujours vérifier la disponibilité (obligatoire).
- Un membre peut éventuellement **prolonger un emprunt** (cas optionnel, conditionné).
- Un **Bibliothécaire** peut : ajouter un livre, retirer un livre, gérer les retards.
- **Gérer les retards** déclenche systématiquement l'envoi d'une notification (obligatoire).

### Travail à faire

1. Liste les acteurs.
2. Liste les cas d'utilisation par acteur.
3. Identifie les relations `<<include>>` et `<<extend>>`.
4. Dessine le diagramme.
