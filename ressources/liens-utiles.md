# Ressources & liens utiles

## Outils en ligne

- [PlantUML Online Server](https://www.plantuml.com/plantuml/uml/) — coller du code PlantUML et voir le rendu instantanément
- [Mermaid Live Editor](https://mermaid.live/) — idem pour Mermaid
- [draw.io](https://app.diagrams.net/) — éditeur graphique classique (glisser-déposer), utile pour des diagrammes plus visuels

## Extensions VS Code recommandées

- **PlantUML** (jebbs.plantuml) — prévisualisation des fichiers `.puml` directement dans VS Code
- **Markdown Preview Mermaid Support** — pour prévisualiser les blocs Mermaid dans les fichiers `.md`

## Documentation officielle

- [Documentation Mermaid](https://mermaid.js.org/intro/)
- [Documentation PlantUML](https://plantuml.com/fr/)
- [Spécification UML (OMG)](https://www.omg.org/spec/UML/)

## Pour aller plus loin

- Le livre *UML 2 par la pratique* (Pascal Roques) — référence classique en français
- Les diagrammes UML restants non couverts ici : diagramme d'objets, de paquetages, de communication, de timing, diagramme global d'interaction
