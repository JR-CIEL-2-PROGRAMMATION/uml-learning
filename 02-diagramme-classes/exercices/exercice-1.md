# Exercice 1 — Système de commande en ligne

## Énoncé

Modélise un système simple de commande e-commerce avec les règles suivantes :

- Un **Client** peut passer plusieurs **Commandes**.
- Une **Commande** est passée par un seul client.
- Une **Commande** contient plusieurs **LigneCommande**.
- Une **LigneCommande** est liée à un seul **Produit**, avec une quantité.
- Un **Produit** a un nom, un prix, et un stock.
- Si une commande est supprimée, ses lignes de commande disparaissent aussi (mais pas les produits).

### Travail à faire

1. Identifie les classes et leurs attributs principaux.
2. Identifie les méthodes utiles pour chaque classe.
3. Détermine le type de relation entre chaque paire de classes (association, agrégation, composition).
4. Détermine les cardinalités.
5. Dessine le diagramme (Mermaid ou PlantUML).

> 💡 Astuce : la règle "si X disparaît, Y disparaît aussi" est un indice fort sur le type de relation à utiliser.
