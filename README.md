## Outils utilisés

- **[Mermaid](https://mermaid.js.org/)** → se rend directement dans les README GitHub, simple et rapide
- **[PlantUML](https://plantuml.com/)** → plus complet, standard utilisé en entreprise

### Visualiser les diagrammes

- **Mermaid** : s'affiche automatiquement dans GitHub si écrit dans un bloc ` ```mermaid `
- **PlantUML** : utiliser l'extension VS Code "PlantUML", ou le [serveur en ligne](https://www.plantuml.com/plantuml/uml/)
